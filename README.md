# SK Tech React Website

Modern React implementation of the SK Tech Academy public website.

## Included

- Public home page and SK Tech branding
- Live interview dashboard with conflict highlighting
- Live job openings from Google Sheets
- Interview scheduling form backed by Google Apps Script
- Responsive desktop, Android and iOS layouts

Login, Firebase Authentication, Firestore, candidate pages and admin pages are intentionally excluded.

## Development

Run `npm install`, then `npm run dev`. Create a production build with `npm run build`.
